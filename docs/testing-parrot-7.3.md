# Validación en Parrot OS 7.3

Realizar primero en una VM amd64 con snapshot.

- [ ] Instalación limpia en Parrot 7.3.
- [ ] `apt-get update` sin errores.
- [ ] Todos los paquetes tienen candidato.
- [ ] BSPWM aparece en el selector X11 e inicia.
- [ ] El escritorio KDE/MATE anterior sigue disponible.
- [ ] SXHKD responde y recarga.
- [ ] Polybar se inicia en uno y varios monitores.
- [ ] Picom funciona sin artefactos.
- [ ] Kitty y Rofi funcionan.
- [ ] Zsh, Powerlevel10k y fzf funcionan.
- [ ] Neovim abre en modo normal y headless.
- [ ] Red cableada y Wi-Fi se detectan.
- [ ] VPN `tun*`, `tap*` y `wg*` se detecta.
- [ ] `targetctl` valida, muestra y elimina estado.
- [ ] Batería se oculta en equipos sin batería.
- [ ] Temas claro y oscuro cambian correctamente.
- [ ] Los repositorios de Parrot no cambian.
- [ ] Segunda ejecución sin cambios destructivos.
- [ ] Backups restaurables.
- [ ] Desinstalación conserva paquetes preexistentes.
