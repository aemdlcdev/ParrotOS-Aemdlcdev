# Registro clean-room

La referencia se utilizó para enumerar comportamientos. El código, la documentación, los temas, mensajes, nombres internos y configuraciones de este repositorio se escribieron de nuevo.

Prohibiciones permanentes:

- importar archivos o commits de la referencia;
- copiar configuraciones completas;
- almacenar sus binarios, fuentes o imágenes;
- atribuir a Aemdlcdev trabajo de terceros;
- conservar rutas o datos personales ajenos.

Las coincidencias inevitables con comandos estándar de Linux no implican procedencia compartida.
